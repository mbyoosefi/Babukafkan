# Babuk Recovery v3.0.1

<div dir="rtl" align="right">

نسخهٔ اصلاحی با تمام فایل‌های نهایی ابزار، راهنمای فارسی و انگلیسی و آزمون‌های بازیابی.

دو آزمون تزریق خطا در ویندوز، مسیرها را پیش از مقایسه یکسان‌سازی می‌کنند تا اختلاف شکل مسیر مانع شبیه‌سازی شکست نوشتن و قطع تغییر نام نشود. منطق تعمیر، دروازه‌های ایمنی و بازگشت تراکنش‌ها تغییر نکرده‌اند.

هر ۷۵ آزمون مصنوعی روی آخرین اصلاحات موفق است. نسخهٔ پیشین و برچسب آن محفوظ می‌مانند. آزمون عملیاتی روی میزبان واقعی هنوز انجام نشده است.

بستهٔ پیوست شامل کد، تمام ابزارهای مکمل و تاریخی، مستندات و آزمون‌هاست. ابتدا راهنمای کامل را بخوانید و تحلیل بدون تغییر انجام دهید. ابزارهای تاریخیِ دارای قابلیت نوشتن، زیر پوشش موتور تراکنش جدید نیستند.

## English

This maintenance release includes the final recovery implementation, companion utilities, complete bilingual documentation and synthetic regression suite. Windows fault-injection tests normalize paths before matching source operations. Recovery behavior and safety gates are unchanged from 3.0.0.

All 75 synthetic tests pass on the corrected suite. Live ESXi/VMFS validation is not claimed. The previous release and tag remain available.

The attached toolkit ZIP contains code, documentation, historical utilities and tests; SHA-256 checksums are supplied separately. Start with the manual and a read-only analysis. Historical write-capable utilities are not covered by the new transaction engine.
